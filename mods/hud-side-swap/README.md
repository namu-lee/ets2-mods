# [ETS2 Mod] HUD Side Swap

Swaps the left and right desktop HUD widget stacks in Euro Truck Simulator 2.

## Installation

Subscribe to the official [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3841187300) item.

Or download `ets2-hud-side-swap.scs` from [GitHub Releases](https://github.com/namu-lee/ets2-hud-side-swap/releases). Copy it to the game's `mod` folder and enable **HUD Side Swap** in Mod Manager.

## Compatibility

This mod may conflict with other mods that change the HUD widget layout.

## Development

From the repository root, build `mods/hud-side-swap/build/ets2-hud-side-swap.scs` with Python 3.12.

```powershell
python scripts/build.py mods/hud-side-swap
```

See the [shared build and release guide](../../README.md) for Workshop packaging and release tags.
