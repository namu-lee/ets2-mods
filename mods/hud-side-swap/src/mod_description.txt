HUD Side Swap

Source code
https://github.com/namu-lee/ets2-hud-side-swap

Description
Swaps the left and right groups of HUD widgets on the driving screen.

- On left-hand-drive vehicles, the minimap moves to the left and the HUD speedometer moves to the right.
- On right-hand-drive vehicles, the minimap moves to the right and the HUD speedometer moves to the left.

Compatibility
- Tested on ETS2 1.62.3.3.
- May conflict with mods that change the HUD widget layout. If two mods change the same layout, the higher-priority mod takes precedence.
