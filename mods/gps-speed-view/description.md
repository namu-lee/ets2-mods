# Dashboard GPS Speed: Enhanced View

[Source code](https://github.com/namu-lee/ets2-mods)

[Screenshots by vehicle](https://github.com/namu-lee/ets2-mods/tree/main/mods/gps-speed-view/screenshots)

> ***Note:** This mod and the edition below replace the same GPS layouts. Use only one at a time.*
>
> - *[Dashboard GPS Speed and Limit](https://steamcommunity.com/sharedfiles/filedetails/?id=3841119859)*

## Description

Adds a speed limit and current speed indicators to dashboard GPS, with adjusted pitch and position.

- Supports all SCS trucks and Coaches equipped with a factory GPS.
- Sets the dashboard GPS 3D pitch to 40°.
  - **The HUD minimap's 3D pitch also changes from 40° to 61.54° as a side effect.**
- Moves the vehicle marker about 30% below the center of the dashboard map in both 2D and 3D.

## Compatibility

- Compatible with ETS2 1.62 and later.
- May conflict with mods that modify GPS layouts, dashboards, or map settings. If two mods conflict, the higher-priority mod takes precedence.
