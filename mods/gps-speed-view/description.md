# Dashboard GPS Speed & Forward View

Shows current speed and the speed limit on factory GPS screens. The 3D map uses a 40-degree camera pitch and places the vehicle marker about 20% up from the bottom of the map so more of the road ahead is visible.

For ETS2 1.62. The marker placement also applies in 2D. The shared map setting changes the HUD minimap's 3D pitch to about 61.54 degrees.

Use this edition on its own. It includes the speed and limit displays from [Dashboard GPS Speed and Limit](https://github.com/namu-lee/ets2-mods/tree/main/mods/gps-speed). It can conflict with mods that replace GPS layouts, dashboards, or map settings.
