# [ETS2 Mod] No Minimap

Hides the HUD minimap on desktop and in VR. Keep the Navigation widget enabled to see the clock, rest indicator, mandatory break timer, and route ETA.

## Compatibility

No Minimap may conflict with other mods that modify the Route Advisor.

## Development

From the repository root, build `mods/no-minimap/build/ets2-no-minimap.scs` with Python 3.12.

```powershell
python scripts/build.py mods/no-minimap
```

See the [shared build and release guide](../../README.md) for Workshop packaging and release tags.
